Put your face beside Teachy

Same player Farza’s intro uses. Film short parts, drop the stream URL on every goal, and learners watch you float next to the cursor — then do the work on their Mac.

  1. 1
    Film short parts

    2–8 minutes each. One part ≈ one goal. Upload to Mux (or any HLS/mp4 CDN).

  2. 2
    Write open course JSON

    Set teacherName, teacherVideoURL, and optionally teacherVideoNotes + teachingContext on each goal so Teachy knows what you covered and how to coach. Legacy introVideoURL still works. See courses/README.md and the video template.

  3. 3
    Host & share

    Put the JSON on GitHub. Learners paste the URL into Teachy → Learn → Add.

  4. 4
    Get on the wall

    PR an entry into academy/registry.json so the site and app can feature you. 

{  "teacherName": "Your Name",
  "teacherVideoURL": "https://stream.mux.com/YOUR_PLAYBACK_ID.m3u8",
  "coachAsk": "Look at my screen and coach me…",
  "doneWhen": "Natural-language success check…"
